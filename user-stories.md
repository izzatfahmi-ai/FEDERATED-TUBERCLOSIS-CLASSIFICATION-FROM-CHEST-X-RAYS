# User Stories

1. As a clinic doctor in a low-prevalence screening area, I want an AI tool with high active-TB sensitivity, so that I don't accidentally miss a subtle TB case just because our local clinic sees mostly healthy patients.
2. As a Hospital Data Protection Officer, I want a privacy-first AI model that shares abstract model weights instead of raw images, so that our facility remains fully compliant with PDPA 2010 regulations.
3. As an AI developer, I want a lightweight client-side loss adjustment, so that I can fix class imbalance bottlenecks without adding complex server overhead or extra network lag.
